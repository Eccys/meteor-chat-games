# Meteor Chat Games Addon

This is a Meteor Client addon. It plays chat games for you.

## Features

- Solves trivia fast.
- Solves math.
- Solves unscramble words.
- Solves reverse text.
- Solves fill in the blank games.
- Solves variable match.
- Uses random delays.
- Sends answers to chat.

## How to Use

1. Drop the jar into your mods folder.
2. Open Minecraft.
3. Open Meteor GUI.
4. Turn on Auto Chat Game.
5. Set delay and randomness.

## Settings

- **Delay**: Wait time in milliseconds.
- **Randomness**: Random delay range.
- **Auto Send**: Sends answers to chat.
- **Chat Prefix**: Add command prefix.
- **Chat Feedback**: Prints answer in chat.

## Installation

Build with Gradle:

```bash
./gradlew build
```

Copy the jar from build/libs to your mods folder.
